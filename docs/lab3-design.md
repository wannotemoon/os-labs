## 先理解三个概念

虚盘文件：电脑上的一个普通二进制文件。我们在它的内部模拟磁盘，不把命令直接交给 Windows。

FCB：一个文件或子目录的目录项。记录它叫什么、是什么类型、何时创建、多大、首个磁盘块在哪里。
目录本身占磁盘块，块内存放它的子项 FCB；由这些引用形成目录树。

FAT：按磁盘块号索引的表。一个表项表示该块空闲、已是链尾，或者下一个块的块号。
例如文件的 firstBlock 为2，FAT[2]为5，FAT[5]为LAST_BLOCK，说明它占用2号和5号两个块。
FCB 找到链首，FAT 连接后续块，虚盘文件中对应的数据区保存实际块内容。

## 类关系与数据归属（拟议，待确认）

```text
main / 文件系统命令入口
  ├─ ProcessManager → MemoryManager → Bitmap       已有实验一、二
  └─ FileSystem → DiskManager → 虚盘文件             实验三
       │              │
       │              └─ 文件流、FAT缓存、磁盘块读写和分配回收
       └─ 当前路径、目录项解释、目录树操作和命令语义
```

FCB 是普通数据结构，不负责读写文件，不新增一套节点管理器。
FileSystem 持有一个 DiskManager；DiskManager 持有文件流和 FAT 数组缓存。
FAT 缓存与虚盘中的 FAT 对应，成功修改后同步；块空闲情况由 FAT 判断，不再另外维护 Bitmap。

目录树保存在虚盘的目录项中，不另建一棵长期驻留内存、需要重复同步的 child/next 树。
FileSystem 仅保存当前导航路径（目录名和首块号组成的路径栈）；目录项按需读取。
FCB 是目录项；PCB 是进程控制块，二者职责不同，不给 PCB 加文件系统字段。
文件系统磁盘块也不占用实验二的物理页框或置换块。

主菜单后续新增文件系统入口，进入后使用命令行，返回时仍可操作原来的进程、分页功能。

## 磁盘布局与数据表示（拟议，待确认）

- 先采用64个数据块，每块1024字节；讲义允许8至1024个块，后续可调整。
- FAT16：每项2字节，64项共128字节。布局为 `[FAT | 64个数据块]`，总文件长度65664字节。
- 数据块号从0开始；0号块固定给根目录，永不分配给其他文件，也不允许删除根目录。
- EMPTY_BLOCK 为0x0000，LAST_BLOCK为0xFFFF，沿用讲义。根块固定保留后，普通文件链不需要指向0号块，避免与空闲标记混淆。
- 新目录起初分配1个块；目录项满时拟通过FAT扩展目录链。普通文件按字节数向上取整分配数据块。
- 建议磁盘目录项固定32字节：名称8、大小4、首块号4、类型1、创建时间15。
- 内存中的 FCB 可使用 string 和 int；磁盘格式显式编码/解码，不能把含 string 的 C++ 对象直接写盘，也不依赖 sizeof(FCB)。
- 名称字段暂拟最多8个UTF-8字节，不等于8个中文字符；日期字段为15个ASCII字节，格式 `yyyymmdd hhmmss`，不附加终止符。
- 类型0表示未使用或已删除，1表示文件，2表示目录。DIR 将日期、时间转换成讲义示例的可读格式。
- 文件大小为逻辑字节数；目录大小拟记0，实际占用块数由FAT链决定。空文件拟允许大小0、首块号-1，不占数据块。
- 数据块读写偏移为FAT字节数加块号乘1024；块号不直接当成文件字节偏移。
- 若虚盘不存在则创建；若存在则打开并核对布局，不能每次启动自动格式化，更不能因文件不合法而覆盖它。
- 虚盘、临时文件与构建产物不提交Git；正式加入虚盘路径时同步增加准确的忽略规则。

上述容量、名称限制、空文件和路径规则是供讨论的项目约定，不冒充讲义明确规定。

## 接口讨论草案

这里只列建议签名与约定，不创建对应头文件。确认后再结合现有代码风格落地。
bool方法成功返回true；失败返回false，并可通过 `getLastError()` 获取最近一次失败原因。
业务错误由命令入口打印一次，底层磁盘操作不直接输出“创建成功”等提示。

DiskManager 只处理磁盘和块，不理解MD、CD或文件名：

| 建议接口 | 职责与边界 |
|---|---|
| `bool openDisk(const string& path)` | 打开已有虚盘，或在不存在时创建新虚盘；失败不覆盖已有文件 |
| `bool readBlock(int blockNo, vector<char>& buffer)` | 读一个完整块；成功输出1024字节，拒绝越界块号 |
| `bool writeBlock(int blockNo, const vector<char>& buffer)` | 写一个完整块；只接受1024字节缓冲区，检查写入结果 |
| `bool allocateBlocks(int count, int& firstBlock)` | 分配并连接若干空闲块；count须为正，空间不足不残留部分分配 |
| `bool getChain(int firstBlock, vector<int>& blocks)` | 按顺序取得块链，检查越界、空闲链和循环链；失败记录原因 |
| `bool extendChain(int firstBlock, int count)` | 给已有链追加块，用于目录扩展；空间不足不改变原链 |
| `bool freeChain(int firstBlock)` | 回收合法块链；先核对整条链，不释放根目录块；空链规则单独处理 |
| `int getFreeBlockCount() const` | 由FAT统计空闲块，不修改磁盘 |
| `void showFat() const` | 辅助验收，查看空闲标记、块链接和链尾 |
| `const string& getLastError() const` | 获取磁盘操作失败原因 |

FileSystem 按目录项组织文件系统，磁盘读写交给DiskManager：

| 建议接口 | 职责与边界 |
|---|---|
| `bool open(const string& diskPath)` | 初始化虚盘和根目录导航状态；新旧虚盘分别处理 |
| `bool makeDirectory(const string& name)` | 当前目录下创建空目录；检查名称、重名和空间 |
| `bool changeDirectory(const string& target)` | 切换到合法目录；失败不改变当前路径 |
| `bool removeDirectory(const string& name)` | 只删当前目录中的空子目录；拒绝文件、根、`.`和`..` |
| `bool makeFile(const string& name, int sizeBytes)` | 创建指定字节大小的文件；检查负数、重名和空间，按需分配块 |
| `bool deleteFile(const string& name)` | 只删除普通文件并回收全部块，不把目录当文件删除 |
| `bool listDirectory()` | 按图4-1输出当前目录，读盘失败返回false |
| `string getCurrentPath() const` | 返回带根和尾部分隔符的路径，例如 `\test\` |
| `const string& getLastError() const` | 获取业务或下层I/O失败原因 |

内部可使用少量直接的辅助方法：查找当前目录项、读写一个目录项、验证名称、生成时间字符串。
具体参数等FCB字段确认后再声明，避免提前设计大量封装。
FileSystem负责FCB的磁盘编解码；DiskManager只读写原始块和FAT。

命令入口逐行读取，解析关键字和参数；只转换命令关键字的大小写，不擅自改变文件名。
拟支持 `MD name`、`CD name`、`CD ..`、`CD \`、`RD name`、`MK name sizeBytes`、`DEL name`、`DIR`。
文件名大小写是否区分、是否支持多级路径、空格名称以及退出命令，需要在写解析器前确认。
后续可提供独立的FAT/空间查看入口辅助截图，不给六个命令额外打印成功信息。
