## 讲义要求与项目约定的区别

来源：上级目录《【操作系统原理】实验讲义 1.doc》“四、进程调度”。本轮重新核对原文。

讲义要求在前三个实验基础上，连续调度全部进程，支持FCFS、SJF和时间片轮转；创建时输入到达/服务时间，适当展示队列变化及已执行/剩余时间，计算每进程的周转时间、带权周转时间和两个平均值；提供完成队列便于统计。

以下为本项目的设计安排，不冒充讲义固定实现方式：

- 使用逻辑时间，不sleep等待；尚未到达、就绪、运行、完成分别表示不同阶段，尚未到达不是阻塞。
- SJF采用上轮讲解的非抢占方式，按总服务时间burstTime选择，不做最短剩余时间抢占。
- 相同到达时间保留输入先后；SJF服务时间相同则选择原就绪队列中靠前的节点，不额外按名称排序。
- RR片末与新进程同时到达时，建议先加入本片期间和片末的新到达者，再将未完成的运行者放回队尾；这是待统一写入主循环和测试的项目顺序，不是讲义逐项规定。
- 模拟时钟及累计时间使用long long；非负到达时间、正服务时间、正RR时间片，以及时间累加上界由上层校验。队列只负责组织节点，不重复做业务输入检查。

## 类关系与数据归属

沿用已有简单结构，不新增一套与现有PCB、分页完全脱节的调度程序。

```text
实验四入口（后续接入，使用独立的ProcessManager实例）
  └─ ProcessManager：进程所有权、模拟时钟、算法选择、调度循环、时间统计
       ├─ PCBQueue：待到达 / 就绪 / 完成队列；running保存当前运行者
       ├─ PCB：身份、到达/服务/已执行/完成时间，以及已有分页信息
       └─ MemoryManager：沿用分页分配与回收接口，不决定谁先运行
```

原有手动进程/分页菜单保留，不把主菜单中已经运行的进程混进新建的自动模拟任务；文件系统不变。具体ProcessManager方法和菜单参数将在队列辅助方法完成后确认，本轮不提前改动这些接口。

一个PCB的next只能服务于一个链式队列，必须先从旧队列摘出，再进入新队列。PCB的创建/删除属于ProcessManager；队列不能擅自delete节点。

完成时应先回收分页资源，再保留PCB或结果到完成队列用于统计，不能照搬原terminateProcess立即delete的逻辑；最后退出/重置时统一清理。完成记录的时间字段不随内存回收而清空。

## 本轮PCB字段

保留原READY、RUNNING、BLOCKED的数值，追加NOT_ARRIVED、FINISHED。新字段仅供实验四，原手动模式仍按原逻辑运行；旧模式PCB默认burstTime=0不表示合法的自动调度任务。

| 字段 | 类型/默认值 | 职责 |
|---|---|---|
| arrivalTime | long long / 0 | 允许进入就绪队列的模拟时刻 |
| burstTime | long long / 0 | 总CPU服务时间；自动任务必须大于0 |
| executedTime | long long / 0 | 累计已执行时间；剩余量由burstTime减去它得到 |
| finishTime | long long / -1 | 完成时刻；-1表示还没有完成 |

周转时间=finishTime-arrivalTime；带权周转时间=周转时间/burstTime，必须浮点除法。平均值按实际完成进程数计算；零进程不能除以零。为避免相互矛盾，不再保存另一份“剩余时间”。

## 第一轮：用户实现两个队列方法

### void PCBQueue::pushByArrival(PCB* p)

- 原队列按arrivalTime非递减排列，传入未入队节点，返回void。
- nullptr不改变队列；实际插入后count加1。
- 相同到达时间插在已有同时间节点之后；正确维护head、tail和next。
- 不分配、删除PCB，不推进时间，不改变状态或其他时间字段。
- 上层负责非负时间与节点所有权；不能将同一个PCB重复插入或同时插入不同队列。

### PCB* PCBQueue::popShortest()

- 空队列返回nullptr，其他状态不变。
- 取出burstTime最小的节点；并列时保留原队列中的先后。
- 只摘链，其他节点相对顺序不变；更新head、tail、count，被取出节点next为空。
- 不delete节点、不改变状态/时间/分页数据；调度器以后再把返回节点设置为RUNNING。

框架准备时pcb_queue.cpp只放置任务块和边界提示，没有提供函数实现；用户随后自行完成两个定义，首次运行复查结果见文末。现有菜单暂未调用这两个方法，因此主程序能运行不代表新方法正确。
