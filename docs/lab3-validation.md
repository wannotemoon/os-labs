## 怎么运行

在CLion重新加载CMake并运行os，主菜单选择12。

- 虚盘路径直接回车使用当前工作目录的os-lab3.disk；也可输入自己的完整路径。
- 数据块数直接回车使用64；传8可复现讲义。已有虚盘必须使用原来的块数，配置不匹配会拒绝，不会重新格式化。
- 命令关键字不区分大小写，名称区分大小写、最多8个UTF-8字节，不含空白及保留标点。不支持引号包裹空格名称或多级路径。
- EXIT返回原菜单；主菜单0退出。EOF同样正常结束输入。
- *.disk虚盘文件不是源码，不提交。默认文件位于运行工作目录，不一定是项目目录，可在CLion运行配置中查看工作目录。

```text
MD test
CD test
MK zero 0
DIR
CD ..
CD \
RD test
MK a.c 2000
DEL a.c
info 0
EXIT
```

其中RD test会因zero仍存在而报“目录非空”；应先CD test、DEL zero、CD ..再RD test。DIR、CD和info有规定输出；其他四个操作成功后只返回路径提示符。单独CD可显示当前路径。info的偏移是整个虚盘文件的十进制字节偏移，不是数据块号；默认显示256字节，到文件尾自动缩短。

## 讲义截图演示顺序

使用全新路径，例如lab3-demo-8.disk，块数选择8。不要对已有作业虚盘使用覆盖/清空操作；同路径重开会继承原数据。

1. info 0：初始FAT只有0号根块为FFFF，整个文件8208字节。
2. MD test，再DIR、info 0：test大小1024、首块1；FAT[1]=FFFF。
3. MK a.c 2000，再DIR、info 0：a.c首块2，占2、3号块，FAT[2]=3、FAT[3]=FFFF。
4. CD test、CD ..：观察路径从根到子目录再回根。
5. RD test，再DIR、info 0：test不再显示；FAT[1]=0，旧目录项仅类型改0，因此info仍可能看见test名称。
6. EXIT后重新进入同一虚盘和8块配置：a.c及其FAT链仍在；DEL a.c后2、3号块全部回收。

这些步骤沿用讲义案例；空文件、目录扩展和失败输入是项目补充测试，不冒充讲义单列加分。创建日期取本机本地时间，不要求与讲义截图逐字节相同。

## 实现范围和边界

六命令、树型目录、FCB/FAT16外存保存、info、关闭重开，以及目录超过32项后按块扩展均已实现。每次目录业务操作检查可达树的链和目录项，防止循环、交叉占块及大小不符；不自动修复损坏数据或回收无主已分配块。

目录大小记录实际分配的空间，删除子项不会自动收缩；子目录扩容会更新其父目录的FCB。文件逻辑大小按输入记录，分配块数向上取整；0字节文件不占块。文件内容编辑、递归删除、多级路径、权限、多用户和实验四不在本轮范围。

参数错误、重名、空间不足均在写入前拒绝。真实I/O失败仅尽力恢复，可能已发生部分写入；目录扩展与父目录大小更新也不是原子事务。未验证突然断电、磁盘写满或内存耗尽，不宣称具有日志文件系统的恢复能力。
