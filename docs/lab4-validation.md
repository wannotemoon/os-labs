# 实验四基础版：运行与验证

日期：2026-11-05。范围为FCFS、非抢占式SJF、RR、过程显示和周转统计；优先级结合调度与银行家算法留后续讨论。

## 在CLion运行

刷新CMake后运行os，主菜单选择13。实验四子菜单中1为FCFS，2为SJF，3为RR，0返回原菜单。

先选择算法，RR再输入正整数时间片，然后输入进程数。每个进程占一行，格式为：

```text
名称 大小(字节) 到达时间 服务时间 驻留页数
```

例如A 1024 0 3 1表示A占1024字节、时刻0到达、需3单位CPU时间、驻留1页。驻留页数也可填-1使用原默认规则。每批1到64个进程，创建时预分配分页资源；创建失败可修改当前任务重输，单独输入0取消本批。

每批独立管理；运行结束后可直接选择另一个算法并输入新批次。它不会修改原主菜单中已经创建的手动进程。

## 可直接输入的RR样例

```text
13
3
2
2
A 1024 0 3 1
B 1024 2 1 1
0
0
```

前四行依次是进入实验四、选RR、时间片2、进程数2；最后两个0分别返回主菜单和退出程序。

执行片段为A[0,2]、B[2,3]、A[3,4]。时刻2先收取B，再把未完成的A放到就绪队尾。

| 完成顺序 | 到达 | 服务 | 完成 | 周转 | 带权周转 |
|---|---:|---:|---:|---:|---:|
| B | 2 | 1 | 3 | 1 | 1.000 |
| A | 0 | 3 | 4 | 4 | 1.333 |

平均周转时间为2.500，平均带权周转时间为1.167。数值显示三位小数，计算使用完整精度。

周转时间=完成时间-到达时间；带权周转时间=周转时间/服务时间；两个平均值分别对每行的对应结果求平均。完成队列为空时不计算平均数；中途失败时只展示已经完成的记录并明确提示。

## 正式测试

在已配置好CLion工具链的终端中，可使用当前构建目录运行：

```text
cmake --build cmake-build-lab2-verification
ctest --test-dir cmake-build-lab2-verification --output-on-failure
```

若CLion实际构建目录是cmake-build-debug，请将目录参数替换为该目录。CMake找到Python后会注册实验三的两组测试和实验四CLI测试。新测试也可单独运行：

```text
python tests/lab4_cli_tests.py cmake-build-lab2-verification/os.exe
```
